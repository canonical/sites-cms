# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub: open the **Security** tab of this
repository and choose **Report a vulnerability**. If you cannot use GitHub,
email security@ubuntu.com.

Include what you found, how to reproduce it, and what an attacker could do
with it. We will confirm we have received the report and keep you informed
while we fix it.

Canonical's wider disclosure policy:
https://ubuntu.com/security/disclosure-policy
